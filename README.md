**Tracks**

- [STAR Stories](star-stories/) — behavioral interview stories

## Target roles

This repo prepares for **Senior Software Engineer**, **Team Lead / TLM**, and **Staff Engineer**
loops together. The knowledge is shared; what changes is the altitude the answer is delivered at
and which rounds appear in the loop. See
[interview-prep-plan.md § Part 0 and Part 1](interview-prep-plan.md#part-0--which-loop-are-you-actually-in).
