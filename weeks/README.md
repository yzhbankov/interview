## How to use a week file

1. **Monday:** read the Goal and *Due by Sunday*. That's the contract.
2. **Each session:** only that day's section. Stop at the end of the block.
3. **Each session ends with *Done when*.** If it isn't true, carry it — don't tick it.
4. **Friday, 15 min:** fill your row in the [tracker](../interview-prep-plan.md#part-6--progress-tracker), pick one fix.
5. **Sunday:** check the *Week gate*. Failed two weeks running → change the *format* (add a human, a timer, a recording), not the reading.

## If you fall behind

Drop Mon/Tue coding first — it decays slowest and recovers fastest. Never drop Thursday, and never
drop the Saturday mock: it is the only session that measures you rather than teaches you.

## Running short on time

Fewer than 8 weeks: run [1](week-01.md) → [3](week-03.md) → [6](week-06.md) → [8](week-08.md).
Fewer than 4: see [compressed variants](../interview-prep-plan.md#part-5--compressed-variants).
