## How to use a week file

1. **Monday morning:** open the week, read the Goal and the *Due by Sunday* box. That's the contract.
2. **Each session:** work only that day's section. Stop at the end of the time block.
3. **Each session ends with *Done when*.** If it isn't true, the session isn't finished — carry it, don't tick it.
4. **Friday:** 15 minutes. Fill your row in the [tracker](../interview-prep-plan.md#part-6--progress-tracker), pick one fix.
5. **Sunday:** check the *Week gate* at the bottom. A failed gate two weeks running means change the practice *format* — add a human, a timer, or a recording — not more reading.

## If you fall behind

Skip Monday/Tuesday coding before you skip anything else — coding decays slowest and recovers
fastest. Never skip the Saturday mock; it is the only session that measures you rather than
teaches you.

## Running short on time

Fewer than 10 weeks: run [1](week-01.md) → [4](week-04.md) → [7](week-07.md) → [10](week-10.md).
Fewer than 4: see [compressed variants](../interview-prep-plan.md#part-5--compressed-variants).
